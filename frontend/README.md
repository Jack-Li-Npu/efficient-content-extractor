# Local transcript interface

React + Vite frontend for the caption extractor. See the [application README](../README.md) for installation, proxy settings, API behavior, and verification.

Run `npm ci` then `npm run dev -- --host 127.0.0.1` for development with the backend on port 8000. `npm run build` creates the static files served by FastAPI. Run `npm test` and `npm run lint` for checks. Production requests always use the current local server.
